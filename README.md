# Website Filadélfia
Um portal de notícias da comunidade Filadélfia, permitindo que usuários publiquem, editem e visualizem conteúdos.

## Descrição
Este projeto é um sistema de gerenciamento de notícias, ideal para comunidades ou blogs. Ele oferece autenticação de usuários, CRUD completo de notícias e pesquisa por título.

## Tecnologias
- **Next.js 14** – framework React com SSR e API Routes
- **Drizzle ORM** – ORM moderno para PostgreSQL
- **PostgreSQL** – banco de dados relacional
- **Tailwind CSS** – estilização responsiva
- **TypeScript** – tipagem estática
- **Better-Auth** – autenticação de usuários

## Funcionalidades
- Cadastro e login de usuários
- CRUD de notícias (criar, ler, atualizar e excluir)
- Upload opcional de imagens
- Pesquisa de notícias por título
- Ordenação de notícias por data
